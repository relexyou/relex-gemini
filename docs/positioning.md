# Positioning — Relex × Gemini

**Relex doesn't replace Gemini. It helps you use Gemini end-to-end.**

Confidential client data, firm know-how, payments, and intake are the missing
layer around the model. Relex provides that layer with cryptographic PII sealing
and MCP-enforced deep links so Gemini never receives plaintext client identities
or documents.
